# My Training Tracker 🏋️‍♂️

My Workout Tracker — це сучасний веб-застосунок для планування тренувань та моніторингу спортивних досягнень у реальному часі.

🎯 Концепція MVP (Minimum Viable Product)

Основна мета застосунку — надати користувачу простий інструмент для швидкого створення вправ без зайвих налаштувань. Дані зберігаються локально, що забезпечує конфіденційність та миттєвий доступ до історії занять.

🚀 Основний функціонал

Динамічне планування: Створення черги вправ з адаптивними полями вводу залежно від категорії (Силові, Кардіо, Стрейчинг).

Інтелектуальні підказки: Відображення останнього результату для конкретної вправи для стимулювання прогресу.

Редагування: Можливість змінити параметри запланованої вправи перед її фіксацією в історії.

Денний трекер: Візуальне підтвердження завершених завдань за поточну дату.


💻 Стек технологій

Core: Vue 3

Build Tool: Vite

Styling: CSS3 (Scoped)

Storage: Web Storage API



🛠 Інструкція з розгортання

1. Клонування репозиторію

git clone <url_вашого_репозиторію>


2. Встановлення залежностей

npm install


3. Запуск у режимі розробки

npm run dev
